CLIPBLOX LOGO
=============
Place the official logo in this folder as one of:

  logo.png
  logo.svg
  logo.webp
  logo.jpg

The website (navbar, hero and footer) detects it automatically and uses it
instead of the built-in stand-in mark. A transparent PNG/SVG with the logo
cropped tightly works best. The logo is never stretched — only its height is
set, the width follows the original aspect ratio.
